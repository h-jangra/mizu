Configuration Reference

Mizu reads its configuration from ~/.config/mizu/config.ini (or $XDG_CONFIG_HOME/mizu/config.ini). If absent, built-in defaults are used automatically.

Configuration Options

1. Bar Dimensions & Geometry

  • height: Status bar height in pixels (default: 42).
  • margin_top, margin_bottom, margin_left, margin_right: Outer screen margins.
  • border_width: Stroke width of bar and pill borders (default: 1).
  • bar_radius: Corner radius of the status bar (default: 12).
  • pill_radius: Corner radius of chips and pills (default: 10).
  • panel_radius: Corner radius of floating overlay panels (default: 16).

2. Typography ([typography])

Logical pixel font sizes (clamped to 8–96): * ui: Standard interface text (default: 15). * secondary: Descriptions and timestamps (default: 13). * heading, title: Section and window headers (default: 18, 20). * bar_text, bar_icon: Bar chip labels and vector icons (default: 15, 20). * quicksettings_text, quicksettings_icon: Quick Settings text and icons. * calendar_text, calendar_heading: Calendar day numbers and navigation.

3. Themes & Theme System

  • theme: Active theme name (default: nord).
  • Built-in themes: nord, dracula, catppuccin, tokyo-night, rose-pine, frosted-neumorphic.
  • Built-in Location: Shipped in /usr/share/mizu/themes/.
  • User Overrides: When a theme is selected, its files are copied to ~/.config/mizu/themes/<theme_name>/ and loaded from the user copy. User modifications are preserved and never overwritten on theme changes.
  • CSS-based Colors & Styling: Each theme directory includes a theme.css file defining CSS variables (--mizu-base, --mizu-accent, --mizu-radius-bar, etc.) and GTK @define-color rules.
  • Automatic SVG Recoloring: SVG icons in theme directories and asset paths are automatically recolored using the active theme's palette where appropriate, with full anti-aliased rendering via Mizu's NanoSVG renderer.
  • Fallback Handling: If a user theme is missing or invalid, Mizu safely falls back to built-in themes without overwriting user customizations.
  • font_family: Primary font family (e.g. Maple Mono NF, monospace).
  • clock_format: Standard strftime format string (e.g. %a %b %d %H:%M).
  • calendar_file: Optional custom .ics calendar file for holiday dates.

4. Modular Layout

  • modules_left: Comma-separated list of left-aligned modules.
  • modules_center: Comma-separated list of center-aligned modules.
  • modules_right: Comma-separated list of right-aligned modules.

Available module names: launcher, workspaces, buttons, keymaps, clock, mpris, recorder, tray, battery, memory, network, bluetooth, volume, quicksettings, theme_switch, separator.

5. Custom Buttons ([buttons])

Add custom quick-launch buttons to the bar (Label = Command):

[buttons]
󰌌 Term = foot
󰈹 Web = firefox
󰅍 Clip = mizu clipboard

6. Custom Panels ([panels])

Register custom overlay panels toggleable via mizu <name>:

[panels]
mixer = pavucontrol
dashboard = foot -e btop

Example Configuration

# Mizu Configuration File
# Location: ~/.config/mizu/config.ini

# Bar dimensions and geometry
height = 42
margin_top = 4
margin_bottom = 0
margin_left = 8
margin_right = 8
border_width = 1
bar_radius = 12
pill_radius = 10
panel_radius = 16

# Font family and clock
font_family = Maple Mono NF, monospace
clock_format = %a %b %d  %H:%M

# Typography (logical pixel sizes, clamped to 8-96)
# ui: standard interface text; secondary: descriptions, timestamps, muted labels
[typography]
ui = 15
secondary = 13
heading = 18
title = 20
bar_text = 15
bar_icon = 20
quicksettings_text = 15
quicksettings_icon = 23
submenu_text = 15
calendar_text = 16
calendar_heading = 19
button_text = 15
keymap_text = 16

# Legacy aliases still accepted: font_size -> ui, bar_font_size -> bar_text,
# panel_font_size -> ui

# Desktop & Lock Screen Wallpaper (PNG, JPEG)
# If not specified, Mizu auto-detects and reuses the active desktop wallpaper without duplicating assets
# wallpaper = /path/to/wallpaper.jpg

# Theme System
# Built-in themes: nord, dracula, catppuccin, tokyo-night, rose-pine, frosted-neumorphic
# Built-in themes ship in /usr/share/mizu/themes/ (or <prefix>/share/mizu/themes/).
# When selected, the theme is copied to ~/.config/mizu/themes/<theme_name>/ and loaded
# from your user copy, preserving your local modifications.
# Each theme directory contains:
#   - theme.css: CSS custom properties (--mizu-base, --mizu-accent, etc.) and GTK colors
#   - icons/: Theme-specific SVG icons (with automatic SVG recoloring via active theme palette)
# Custom user themes can be placed in ~/.config/mizu/themes/<custom_name>/.
theme = nord

# On-screen keymap overlay (mizu keyoverlay)
# Placement: top-left, top-center, top-right, bottom-left, bottom-center, bottom-right
keymap_position = bottom-center
# keymap_font_size = 16

# Calendar holidays (optional)
# Use your own local iCalendar file instead of the built-in India holiday feed.
# Relative paths resolve from ~/.config/mizu (or $XDG_CONFIG_HOME/mizu).
# calendar_file = holiday.ics

# Modular Layout Configuration
# Available modules: launcher, workspaces, buttons, keymaps, clock, mpris, recorder, tray, battery, memory, network, bluetooth, volume, theme_switch, separator
modules_left = launcher, buttons, workspaces, keymaps
modules_center = clock, mpris
# Right modules build from right edge towards left:
modules_right = theme_switch, volume, recorder, tray, bluetooth, network, memory, battery

# Screen Recorder Settings
# When recording: Left-click or right-click stops gracefully (SIGINT triggers save & on-saved notification).
# When idle:
#   - Left-click: prompts window or region selection via slurp, records at constant 60 fps
#   - Right-click: directly records entire screen at constant 60 fps
# On finish: sends a notification popup confirming the saved video in ~/Videos.
recorder_cmd = gpu-screen-recorder -w screen -f 60 -fm cfr -fallback-cpu-encoding yes -o "$HOME/Videos/recording_$(date +%Y%m%d_%H%M%S).mp4"
recorder_hide_when_idle = false

# Quick-launch Custom Buttons (shown when 'buttons' is in modules_left/center/right)
# Label = Shell Command or 'mizu <panel>'
# [buttons]
# 󰌌 Term = foot
# 󰈹 Web = firefox
# 󰉋 Files = thunar
# 󰅍 Clip = mizu clipboard
# 󰸗 Cal = mizu calendar
# 󰒓 QS = mizu quicksettings
# 󰚝 Audio = mizu mixer
# 󰐥 Power = wlogout

# Custom Panels & Drawers
# Registered names can be launched or toggled directly via 'mizu <name>'
# [panels]
# mixer = pavucontrol
# dashboard = foot -e btop
# files = thunar
# notes = foot -e nvim ~/.notes.md
# power = wlogout
# calc = gnome-calculator

# Custom Theme Colors Override (Hex format #RRGGBB or #AARRGGBB)
# bar_bg = #161817
# bar_border = #525E5A
# pill_bg = #525E5A
# ws_active_bg = #DF6124
# ws_active_fg = #161817
# panel_bg = #161817
# panel_border = #525E5A
# network_bg = #282C34
